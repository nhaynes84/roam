# Roam Memory

## P2 Flashing In Sealed Case

- Current Roam P2 is sealed; Nick can power-cycle it but cannot double-tap the XIAO reset button.
- Do not ask Nick to be physically on the reset button. Use the software DFU workaround.
- Normal app USB PID: `0x8045`. Bootloader USB PID: `0x0045`.
- Working sequence verified 2026-07-30:
  1. Build P2 firmware.
  2. Run `adafruit-nrfutil ... --touch 1200` against the app port.
  3. That command may fail because the app port disappears; this is expected.
  4. Wait for the Seeed bootloader PID `0x0045`.
  5. Upload the same DFU zip to the bootloader port without another touch.
- Repo command: `make p2-flash-sealed`.

See [docs/p2-flashing.md](../docs/p2-flashing.md).

## Android Phone Relay

- Android owns the BLE connection in relay mode; do not use Mac `tools/roam-msg` while testing the phone relay because it can take the Roam BLE connection.
- Roam will not advertise while connected to the Mac. Free it first with the on-device BLE switch or by disconnecting/forgetting `Roam2` on the Mac.
- 2026-07-30 live test: Android app connected to Roam and the Mac receiver logged relay events from the phone (`192.168.86.23` -> `192.168.86.63:8765`).
- 2026-07-30 audio fix: stale firmware exposed `FF01`, `FF02`, and `FF04` under `FF00`, but not `FF03`. Current firmware exposes/subscribes `FF03`, drains XIAO PDM audio through an interrupt-fed ring buffer, sends 232-byte ADPCM payloads, and was flashed successfully with `make p2-flash-sealed`.
- 2026-07-30 live audio verification: two Roam PTT sessions relayed sustained audio to the Mac receiver through Android; examples reached seq `74` and seq `99`. Preserved playable capture: `~/Library/Logs/Roam/roam-relay-live-20260730-125233.wav` (6.09s, 16 kHz mono PCM). Current `roam-relay-latest.wav` starts fresh after receiver restart.
- Android may deny foreground-service starts from a background broadcast while locked. For ADB bench starts, wake/dismiss keyguard and launch `MainActivity` with `host`, `port`, and `autoStart` extras.
- 2026-07-30 durable dictation path: run `scripts/start-roam-relay-tmux.sh 8765`. It starts a `roam-relay` tmux session on the Mac, listens on `*:8765`, transcribes PTT with `/opt/homebrew/bin/mlx_whisper`, and injects with `ROAM_RELAY_INJECT_MODE=tmux-submit`.
- Default tmux target is `ROAM_TMUX_TARGET=0:0`. Override it if the active assistant is in a different tmux session/window. This tmux path avoids macOS Accessibility/TCC problems from AppleScript keystroke injection.
